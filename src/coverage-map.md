# Coverage and Maps

Freq51 spans varied terrain. Coverage is useful to explore, but it is never a guarantee that a message will reach a particular place.

## View the Network

Use [MeshView](https://meshview.freq51.net/) to explore reported nodes, links, and infrastructure. You can also use [Malla](https://malla.freq51.net/) for another view of Freq51 mesh activity and network data. The [Infrastructure page](infrastructure.md) provides Freq51-maintained deployment details and site-survey images.

> **Privacy note:** Map positions, node data, and other reported activity may be publicly visible or delayed. Share only the information and location detail you are comfortable making visible.

## How to Read Coverage

- A visible node does not guarantee a usable path from your location.
- Elevation, line of sight, antenna height, buildings, vegetation, and local RF noise all matter.
- Map data is voluntary and can be delayed or incomplete.
- A stationary node with a clear view will usually perform better than a handheld node indoors.

## Improve Your Chances

1. Test outdoors or near a window first.
2. Move the node higher before changing advanced settings.
3. Confirm your region, modem preset, channel, and key match the community configuration.
4. Use the lowest hop limit that reliably reaches your destination.

See [Troubleshooting](troubleshooting.md) if nodes or messages do not appear as expected.
