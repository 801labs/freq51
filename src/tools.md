# Freq51 Tools

[Open all Freq51 tools](https://tools.freq51.net/)

These web utilities support configuration, planning, troubleshooting, and monitoring for the Freq51 community.

## Configure and Plan

- [Node Configurator](https://tools.freq51.net/config/) — Apply Freq51 Meshtastic settings to a node over USB serial or HTTP.
- [Message Rate Calculator](https://tools.freq51.net/message-calculator.html) — Estimate mesh traffic and channel utilization from node counts and broadcast intervals.
- [GPS Coordinate Picker](https://tools.freq51.net/gps-picker.html) — Find latitude, longitude, and altitude from your location or an interactive map.

## Monitor the Network

- [Mesh Chat Viewer](https://tools.freq51.net/chat-viewer.html) — Browse recent mesh chat activity and filter it by channel or sender.
- [System Status](https://tools.freq51.net/status.html) — Check the health of Freq51 services and MQTT feeders.
- [Node Path Tracker](https://tools.freq51.net/node-tracker.html) — View a node’s reported movement history on a map.

> **Privacy note:** Chat history, map positions, node data, and other reported activity may be publicly visible or delayed. Share only the information and location detail you are comfortable making visible.

> Some tools use data reported by nodes and services, so results can be incomplete or delayed. Use [Coverage and Maps](coverage-map.md) and [Getting Help](support.md) when you need context or assistance.
